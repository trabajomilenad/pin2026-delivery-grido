# Delivery Grido – Sistema de Autogestión con IA

## Proyecto PIN 2026

Sistema web para automatizar pedidos del delivery de Heladería Grido Villa del Rosario mediante:
- catálogo digital
- autogestión de pedidos
- control de stock en tiempo real
- integración con WhatsApp
- agente de Inteligencia Artificial

---

## Problemática detectada

Actualmente los pedidos se reciben manualmente mediante WhatsApp y se registran en papel, generando:
- pérdida de pedidos
- errores humanos
- demoras
- falta de control de stock
- sobrecarga operativa

---

## Solución propuesta

Desarrollar una plataforma web responsive que permita:
- visualizar productos
- realizar pedidos
- gestionar stock
- automatizar consultas frecuentes mediante IA
